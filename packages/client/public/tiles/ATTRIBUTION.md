The files here are individual cubes from the pack's "Voxel tiles",
renamed to the terrain they represent:

| File                | Kenney source    | Terrain    |
| ------------------- | ---------------- | ---------- |
| tile-normal.png     | voxelTile_05.png | Normal     |
| tile-water.png      | voxelTile_24.png | Water      |
| tile-ice.png        | voxelTile_06.png | Ice        |
| tile-vegetation.png | voxelTile_03.png | Vegetation |
| tile-earth.png      | voxelTile_53.png | Earth      |
| tile-lava.png       | voxelTile_08.png | Lava       |

Void is drawn procedurally (a pit is not a block).
